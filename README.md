# 🎨 Create Teszt Hez

Welcome to **Create Teszt Hez**, an experimental Minecraft resource pack focused on custom textures, colorful designs, and creative testing!

## 🚀 Latest Version

**1.1.0 Beta — More Textures**

This update introduces more custom textures and additional content compared to version 1.0.0.

## ✨ Features

- 🍏 Custom apple texture
- 💎 Custom diamond block texture
- 🎨 Simple and colorful designs
- 🧱 16×16 texture resolution
- 🔧 Experimental features and ongoing improvements

## 🎮 Minecraft Compatibility

- Minecraft Java Edition 1.20
- Minecraft Java Edition 1.20.1
- Minecraft Java Edition 1.21.11

## 📦 Installation

1. Download the resource pack from Modrinth.
2. Open Minecraft.
3. Go to Options → Resource Packs.
4. Open the resource pack folder.
5. Place the downloaded ZIP file inside.
6. Enable the resource pack and enjoy!
